# MERN Todo DevOps Project

This project demonstrates a complete DevOps pipeline for deploying a MERN Todo application on AWS.

Technologies used:

- AWS EC2
- Terraform
- Ansible
- Docker
- Docker Compose
- Jenkins
- Prometheus
- Grafana
- MongoDB
- GitHub
